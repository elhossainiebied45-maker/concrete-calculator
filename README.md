# حاسبة مقاولات الخرسانة

تطبيق ويب عربي (RTL) جاهز للنشر على **GitHub Pages**، ويمكن تثبيته كتطبيق PWA على الهاتف بعد فتحه عبر HTTPS.

## محتويات المشروع

- `index.html` — التطبيق الأصلي.
- `manifest.json` — بيانات تثبيت التطبيق.
- `sw.js` — Service Worker للتخزين المؤقت ودعم فتح التطبيق دون اتصال بعد أول زيارة.
- `icons/` — أيقونات التطبيق بمقاسي 192 و512.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع كل محتويات هذا المجلد إلى جذر المستودع، وليس ملف ZIP فقط.
3. افتح **Settings → Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر ظهور رابط الموقع في صفحة Pages، ثم افتحه من Chrome على الهاتف.
7. من قائمة Chrome اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.

> مهم: لا تفتح `index.html` من مدير الملفات مباشرة إذا كنت تريد تجربة التثبيت والعمل دون اتصال؛ استخدم رابط GitHub Pages.

## ملاحظات مهمة عن البيانات والحسابات

- التطبيق الحالي يحفظ المشاريع والمستخدمين والنسخ الاحتياطية في `localStorage` داخل المتصفح وعلى نفس الجهاز/المتصفح.
- تسجيل الدخول الحالي محلي داخل المتصفح، وليس نظام حسابات آمنًا على خادم.
- لا توجد مزامنة بين أجهزة مختلفة أو مشاركة تلقائية للبيانات بين المستخدمين.
- مسح بيانات المتصفح قد يؤدي إلى فقدان البيانات؛ استخدم زر النسخ الاحتياطي/الحفظ والتصدير بانتظام.
- لا تضع بيانات حساسة أو كلمات مرور حقيقية؛ هذا الإصدار مناسب للاستخدام المحلي وليس لإدارة مستخدمين عبر الإنترنت.
- الخط Cairo يُحمّل من Google Fonts عند توفر الإنترنت، ويعمل التطبيق بخط بديل عند عدم توفره.

## التحديث لاحقًا

عند تعديل التطبيق، غيّر قيمة `CACHE_NAME` في `sw.js` (مثلًا إلى `concrete-calculator-v2`) حتى يتعرف المتصفح على نسخة التخزين الجديدة.
